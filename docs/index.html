Data engineering project

Live air-quality data, from raw API to tested marts.

AirPulse ingests per-station readings from the WAQI API, models them with dbt into city-level daily marts, flags statistical pollution spikes with a Z-score window function, and serves everything through FastAPI and a live dashboard. CI builds and tests the whole dbt project against a real Postgres.

View the repo Portfolio · ajayramineni.com

The problem

Air-quality monitoring data is published station by station: thousands of independent sensors, with offline stations reporting "-", readings that stop updating for months, and no notion of a normal day for a given city. AirPulse turns that raw feed into a clean, city-level dataset with health categories and spike alerts, and keeps every step re-runnable and tested.

Architecture

One direction of flow, with a clear job for each layer.

Source

WAQI API

Per-station AQI, pollutants and 5-day forecasts for cities with a defined bounding box.

Ingest

Python client + loader

waqi_client.py with retry/backoff, city-feed fallback; db_loader.py with idempotent writes.

Store

PostgreSQL raw

raw.waqi_readings and raw.waqi_forecasts, unique keys enforce idempotency.

Transform

dbt

Staging views, an intermediate daily table, and two mart tables. 25 tests.

Serve

FastAPI + dashboard

JSON endpoints over the marts, plus a single-file HTML dashboard (Leaflet, Chart.js).

stagingclean, type-cast, drop out-of-range AQI, union sources
intermediatecity-day averages + 7-day rolling average
mart · fct_aqi_health_riskEPA category, risk score, day-over-day change
mart · fct_anomaly_eventsZ-score spikes vs. a per-city 30-day baseline

An OpenAQ client and staging model also exist as an optional second source; run_pipeline.py ingests WAQI only.

Key engineering decisions

Each one is something you can verify in the code or in CI.

Idempotent writes

Readings use INSERT … ON CONFLICT (station_id, reading_time) DO NOTHING, so a re-run never duplicates rows. Forecasts use ON CONFLICT … DO UPDATE, so a newer fetch replaces the old one.

Proof: tests/test_db_integration.py runs against a Postgres service container in CI.

Retry with backoff, then fall back

Every API call goes through one method wrapped in tenacity: 3 attempts with exponential backoff (2–20 s) and a 15 s timeout. When a city's bounding box returns no active stations, the client falls back to WAQI's city feed instead of dropping the city.

Proof: ingestion/waqi_client.py.

Medallion-style layers

raw (as landed) → staging views (cleaning, out-of-range AQI dropped, sources unioned) → intermediate (city-day grain) → marts. A new source means one staging model and one line in stg_all__readings; nothing downstream changes.

Proof: lineage screenshot above; dbt build in CI.

Z-score anomaly detection

A fixed AQI threshold ignores that a normal day in one city is a bad day in another. A window function computes each city's mean and standard deviation over up to 29 prior days; a day with Z ≥ 2.5 is flagged (Medium ≥ 2.5, High ≥ 3, Critical ≥ 4).

Proof: CI seeds a synthetic spike and asserts it comes out Critical while a quiet city stays unflagged.
